📐 How scoring works (open methodology)
  1. Same question, every model, at once. Each question is sent to every model with the same instruction. Latency is measured wall-clock per API call; token counts come from each provider's own usage report.
  2. Blind judge. A separate judge model (not competing) sees the question, the reference answer and all answers labelled A, B, C, D in a shuffled order. It never sees model names.
  3. Explicit criteria. The judge scores each answer on the dataset's criteria (shown above, summing to 10) and writes a one-line rationale. The per-criterion scores are visible on every answer.
  4. Accuracy. Mean judge score × 10, with a 95% bootstrap confidence interval over questions. Pass rate = answers scoring ≥ 7/10.
  5. Composite. 0.625 × accuracy + 0.375 × speed (speed = 100 at 0 s, 0 at ≥ 10 s mean latency). Cost is shown but not scored, because every call here runs on a free tier.
  6. Tiers with a safety gate. Production > 85 composite, Analysis > 70 — but a model needs ≥ 85% accuracy for Production and ≥ 70% for Analysis. Models are ranked by accuracy first; a fast but wrong model can't win.
  7. Reliability. Rate limits are retried; overloaded models fall back to a named backup, and every backup answer is flagged. Every run is saved as JSON in data/live_runs/ so results can be audited or replayed.
Full details and source: SCORING.md in the repository · judge prompt in frontend/src/live/judge.js · criteria in frontend/src/live/config.js.

Scoring Methodology
How the recommendation engine ranks models — click to expand

Scoring Formula

final_score = coding×wc + math×wm + reasoning×wr + chat×wch

Each model's raw benchmark score in a category is multiplied by that category's normalized weight, then all four contributions are summed. Weights are normalized so they always sum to 100%, regardless of the values you enter.

Use the sliders in the Recommendation Engine above to shift weights toward your workload — e.g., set Coding to 60 for a software-engineering use case.

Worked Example — Claude Opus 4.7 with equal weights

Coding97.5 × 0.25=24.4
Math93.2 × 0.25=23.3
Reasoning98.2 × 0.25=24.6
Chat96.8 × 0.25=24.2
Final Score=96.4
